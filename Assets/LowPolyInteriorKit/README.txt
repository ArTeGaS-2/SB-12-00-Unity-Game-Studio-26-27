LOW-POLY INTERIOR KIT — Unity

19 окремих FBX-моделей. Один Blender unit = 1 метр. Кожна модель експортується
з координатами (0, 0, 0); точка прив'язки по центру біля підлоги.
У Blender передня сторона меблів спрямована в -Y. FBX експортується для Unity
з Axis Forward -Z, Axis Up Y. Матеріали з простими кольорами вбудовані у FBX.

СТІНИ
Wall_Solid_300 — суцільна стіна, 3.0 x 0.16 x 2.8 м.
Wall_Window_300 — одне вікно, отвір 1.4 x 1.32 м, підвіконня на 0.88 м.
Wall_DoubleWindow_300 — два вікна.
Wall_Doorway_300 — дверний отвір 1.0 x 2.18 м, без дверного полотна.

ПОЛИЦІ Й МЕБЛІ
Shelf_Bookcase_120 — книжкова шафа 1.2 м, з кількома книжками.
Shelf_Industrial_150 — відкрита стійка 1.5 м.
Shelf_Wall_120 — три настінні полиці на спільних опорах.
Shelf_Floating_60 / Shelf_Floating_120 — прості одинарні настінні полиці.
Television_55_Stand — телевізор на ніжці, ширина 1.3 м.
Media_Console_160 — тумба під телевізор 1.6 м.

КУХНЯ
Kitchen_Base_Cabinet_60 — нижня шафа шириною 0.6 м.
Kitchen_Drawers_60 — блок шухляд шириною 0.6 м.
Kitchen_Sink_80 — шафа з мийкою шириною 0.8 м.
Kitchen_Stove_Oven_60 — плита з духовкою шириною 0.6 м.
Kitchen_Upper_Cabinet_60 — верхня шафа, її нижній край на висоті 1.4 м.
Kitchen_Fridge_70 — холодильник шириною 0.7 м.
Dining_Table_140 — обідній стіл шириною 1.4 м.
Dining_Chair — обідній стілець.

РОЗМІЩЕННЯ В UNITY
Стіни мають ширину 3 м і центровану точку прив'язки. Для суміжних стін
ставте центри через 3 м. Полиці Floating мають полицю на висоті 1.43 м
від точки прив'язки. Верхня кухонна шафа ставиться над нижньою з тією ж
координатою X/Z на підлозі. Для проходу використовуйте Wall_Doorway_300.

Це моделі без налаштованих колайдерів і без готової сцени Unity. Якщо потрібні
зіткнення, додайте колайдери у проєкті. Для стін з отворами розміщуйте окремі
Box Collider навколо прорізів або нерухомий Mesh Collider.

Джерело генерації: LowPoly_Interior_Kit/build_kit.py у Blender Workspace.
