# СБ-12-00 — командна розробка гри

Учительська частина командного проєкту 2026–2027. Початковий стан: проста сцена та перевірка кліку по об’єкту. Задум гри — збір предметів за обмежений час і подальше виживання. Командні задачі та інтеграція учнівських частин ще розвиваються.

## Відкриття проєкту

1. Завантажити або клонувати репозиторій.
2. Додати його папку в Unity Hub.
3. Відкрити у Unity 6000.3.15f1 та дочекатися імпорту пакетів.
4. Відкрити Assets/Scenes/SampleScene.unity.

Папки кешу Library, Logs, UserSettings і ProfilerCaptures не входять до Git.
